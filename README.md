# Hi, I'm Dylan 👋

CS student at Northeastern who's been teaching himself to code since 4th grade. I like building things end to end, from the firmware on a microcontroller to the web app that talks to it to the server it's deployed on.

## 💡 What I'm into

- **Embedded & hardware**: ESP32, FreeRTOS, and wiring up LCDs, LED strips, and sensors just to see what I can make them do
- **Full-stack web**: React frontends, TypeScript/Java backends, and real-time stuff over WebSockets and SSE
- **Infrastructure**: self-hosting, Docker, CI/CD pipelines, and running my own servers
- **Machine learning**: training models on real-world datasets
- **Game systems**: large-scale simulation and networking problems in Roblox/Lua
- **AI tooling**: connecting LLMs to real hardware through the Model Context Protocol
